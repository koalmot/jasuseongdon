# House Background Assets

Drop final pixel PNG backgrounds here using these filenames:

- `house0.png`: 빈방
- `house1.png`: 원룸
- `house2.png`: 아파트
- `house3.png`: 펜트하우스
- `house4.png`: 대저택

The current UI uses CSS placeholder rooms. When these PNG files are added, the main scene will use them through the `--house-asset` CSS variable.
